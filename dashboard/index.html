    How the ranking works

    Implied value = size curve × category adjustment × growth factor × maturity factor.

    • Size curve. log(market cap) = a + b·log(TVL), fitted by least squares over the priced protocols in this snapshot — the ones that already have a token. A protocol's curve value is the market cap the curve predicts for its TVL. The curve's slope is below one, so market cap grows slower than TVL: a flat multiple would overprice the largest protocols.
    • Category adjustment. The median residual of the priced protocols in the same category, exponentiated, when the category has at least three priced protocols — and then halved. A category's median residual is a real signal, but it is fitted on protocols that already have a token, and the board prices protocols that do not, so the model takes half of it. A category with fewer than three priced protocols gets no adjustment (1.000) — the curve alone prices it. Adjustments are clamped to 0.25–4.00.
    • Growth factor. 1 + (7-day TVL change, clamped to −60%…+120%) × 0.5.
    • Maturity factor. 0.6 + min(age in days, 1095) / 1095 × 0.4. A protocol with no listing date counts as 365 days old.

    How the model was tested

    Four tests on the same snapshot, each the median absolute error as a multiple of the true market cap — a smaller multiple is a better-tested model. Leave-one-out refits the model without each protocol in turn; walk-forward fits it on the oldest 70% of the priced protocols by listing date and tests it on the newest 30%; five-fold cross-validation shuffles the priced protocols with a fixed seed and holds each fifth out in turn. Halving the category adjustment is what the walk-forward test chose: it is the best of the three variants on the newest protocols, the ones the model has never priced. Cross-validation is reported as a fourth check; on it the variants sit within noise of each other.
